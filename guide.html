Руководство по настройке VPS и панели 3X-UI

Автономная шпаргалка: работает в любом браузере без установки Node.js и программ
● Автономный файл (Offline)
⚠️ Главное правило безопасности: Никогда не закрывайте текущую сессию root, пока не выполните проверку входа во втором отдельном окне терминала командой: ssh -p 22 adminuser@YOUR_SERVER_IP
1
Создание пользователя и sudo
Выполняется под root на сервере:
bash (сервер)
adduser {USER}
usermod -aG sudo {USER}
su - {USER} -c "sudo whoami"
2
Настройка SSH-ключа и строгих прав
Вставьте ваш публичный ключ в файл authorized_keys:
bash (сервер)
mkdir -p /home/{USER}/.ssh
chmod 700 /home/{USER}/.ssh
nano /home/{USER}/.ssh/authorized_keys
chmod 600 /home/{USER}/.ssh/authorized_keys
chown -R {USER}:{USER} /home/{USER}/.ssh
3
Установка панели 3X-UI (Официальный скрипт mhsanaei)
Актуальный официальный скрипт установки:
bash (сервер)
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
Вход в веб-панель: http://YOUR_SERVER_IP:2053
🛡️
Отключение паролей и запрет входа root
Создание изолированного файла конфигурации с максимальным приоритетом:
bash
cat << 'EOF' | sudo tee /etc/ssh/sshd_config.d/99-custom-hardening.conf
Port {SSH}
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
KbdInteractiveAuthentication no
X11Forwarding no
MaxAuthTries 3
EOF

# Проверка синтаксиса:
sshd -t

# Перезапуск службы:
sudo systemctl restart ssh || sudo systemctl restart sshd

# Проверка фактического статуса:
sshd -T | grep -E -i 'permitrootlogin|passwordauthentication|pubkeyauthentication'
🔥
Настройка фаервола UFW
bash
sudo ufw default deny incoming
sudo ufw default allow outgoing

# Разрешаем SSH и панель
sudo ufw allow {SSH}/tcp comment 'SSH Port'
sudo ufw allow {PANEL}/tcp comment '3X-UI Web Panel'

# Разрешаем входящий VLESS Reality
sudo ufw allow 443/tcp comment 'Reality HTTPS'
sudo ufw allow 443/udp comment 'Reality UDP'

sudo ufw enable
sudo ufw status verbose
⚡
Ускорение TCP BBR
bash
cat << 'EOF' | sudo tee /etc/sysctl.d/99-bbr.conf
net.core.default_qdisc=fq
net.ipv4.tcp_congestion_control=bbr
EOF

sudo sysctl --system
sysctl net.ipv4.tcp_congestion_control
Параметры создания подключения VLESS Reality:
  • Протокол: VLESS
  • Порт: 443
  • Транспорт: TCP
  • Безопасность (Security): Reality
  • Dest / SNI: dl.google.com:443 (или www.microsoft.com:443, yahoo.com:443)
  • ShortId: Нажмите «Get New» для генерации короткого ID
  • Ключи: Нажмите «Get New Keys» (сгенерирует Public и Private ключи)
